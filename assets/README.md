# Assets de marca (originales)

- `brand-source/`: logos originales (Montaigne Fix, Grupo Montaigne, Mundana Studio en SVG). Las versiones optimizadas para la web están en `src/assets/brand/`.
- `fonts/helvetica-neue/`: Helvetica Neue LT Std (Light y Bold), la tipografía corporativa de Mundana Studio. Es una **fuente comercial**, así que está excluida de git y solo se usará en local para los informes PDF (Fase 7). La web usa Inter, una fuente libre autoalojada (`@fontsource/inter`).
